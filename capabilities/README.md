# aoa-agents Capability Home

This owner home projects the `aoa-agents-skills` semantic tree without turning
the graph into procedure, runtime, routing, or proof authority.

The tree supports discovery. Typed relations support compatibility and
handoff. One goal's `aoa-task-local-dag-v2` is built at runtime and is never
committed here.

The first external proof may use a landing obligation and a Luna realization,
but neither name belongs to the stable capability identities.
