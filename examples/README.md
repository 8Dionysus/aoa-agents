# Examples

This directory is the human index for public-safe, schema-backed examples of
agent-layer contracts. Examples illustrate published shapes; source objects,
schemas, builders, and validators remain authoritative.

## Shared routes

- Agon formation and formation-trial examples live under
  `mechanics/agon/parts/formation/examples/`.
- Assistant civil formation examples live under
  `mechanics/experience/parts/assistant-civil-service/examples/`.
- Checkpoint reference routes and Alpha reference routes live under their
  respective checkpoint and questbook part-local `examples/` directories.
- Runtime artifact, Titan, antifragility stress, RPG progression, assistant
  projection, Codex refresh-law, recursor, adoption/boundary, agent-service,
  and participant-relation examples live beside their owning part schemas.

## Ownership and safety

Use the nearest part README for a file-level map and the nearest schema for
the contract. Negative fixtures are intentional validation inputs. Do not add
real run history, secrets, private prompts, hidden transport assumptions, or
runtime authority to examples.

The executable validation route is [VALIDATION.md](../VALIDATION.md); the
nearest mechanic or part validator defines which checks apply.
